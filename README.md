# 域用户管理器（Domain User Manager）

一个面向 Windows 管理员的 Active Directory 用户与组管理工具。通过 LDAP / LDAPS 远程连接域控制器，不需要把管理电脑加入域，也不需要安装 RSAT 或额外运行库。

程序是单文件 WinForms 应用，基于 .NET Framework 4.8（Windows 10/11 自带），双击即可运行。

## 功能

### 连接

- 支持 LDAP（389）和 LDAPS（636）远程连接。
- 支持 `域\用户名`、`用户名@域名` 两种账号格式。
- 自动从 RootDSE 读取 `defaultNamingContext`，也可以手动填写基准 DN。
- 自动读取域 DNS 名称、域控制器名称、域 SID。
- 可选择忽略 LDAPS 证书错误；当前版本按需求默认勾选，生产环境建议取消。
- 可保存服务器、端口、用户名和基准 DN；密码默认勾选保存，使用 Windows DPAPI 以当前用户身份加密。
- 连接、操作、错误都记录在底部日志面板和本地审计日志中。

### 域用户

- 搜索用户：按姓名、登录名、UPN、邮箱、描述、DN 模糊查询。
- 新建用户：显示名、名/姓、登录名、UPN、初始密码、密码永不过期选项、下次登录强制改密、启用状态、邮箱、电话、部门、职务、公司、描述、目标 OU。
- 编辑用户：显示名、名/姓、登录名、UPN、邮箱、电话、部门、职务、公司、描述、账户启用状态、移动 OU。
- 修改登录名（sAMAccountName）前会有明确的风险确认。
- 启用 / 禁用账户。
- 解锁账户（清除 `lockoutTime`）。
- 重置密码，可设置“下次登录时必须更改密码”。
- 删除用户，必须手动输入登录名确认。
- 查看用户所属组，添加/移除组成员身份。
- 删除保护和内置账号保护：内置 Administrator、Guest、krbtgt，以及当前连接账号、关键系统对象会被拒绝删除。

### 域组

![组管理界面示意](docs/screenshot-groups.png)

- 搜索组：按组名、组登录名、描述查询。
- 新建组：组名、组登录名、描述、全局/域本地/通用、安全组/通讯组、目标 OU。
- 编辑组：描述、组类型/范围。
- 删除组，必须手动输入组登录名确认。
- 查看组成员（用户、组、计算机、外部安全主体），添加/移除成员。
- 支持组嵌套。
- 内置安全组（Domain Admins、Domain Users、Administrators 等）和关键系统对象禁止删除。

### 通用

- 用户/组列表默认载入前 300 条，支持关键字缩小范围。
- 页签上显示当前列表数量；超过 300 条显示 `300+`。
- 表格状态着色：已启用、已禁用、已锁定。
- 用户详情、组详情、所属组、组成员分别在右侧面板查看。
- `F5` 刷新当前列表，`Ctrl+F` 聚焦搜索框，`F1` 打开关于作者窗口。
- 日志面板可收起，支持打开审计日志目录。
- 高 DPI 屏幕适配。

## 运行要求

- Windows 10 / Windows 11（x64）。
- .NET Framework 4.8（Windows 10 1903+ 和 Windows 11 默认包含）。
- 管理电脑到域控制器的网络可达：
  - LDAPS：TCP 636（推荐）
  - LDAP：TCP 389（不建议用于密码操作）
- 一个具备相应 AD 权限的域账号。
- 如果使用 LDAPS，域控制器需要安装计算机证书；当前版本默认勾选“忽略证书错误”，生产环境建议取消勾选并部署受信任证书。

## 快速开始

1. 双击 `域用户管理器.exe`。
2. 填写“服务器”，例如 `dc01.example.com` 或 `dc01.example.com:636`。
3. 端口保持 `636`，勾选 `SSL (636)`。
4. 填写连接账号：
   - `EXAMPLE\administrator`
   - 或 `administrator@example.com`
5. 填写密码。
6. “基准 DN”可以留空，程序会自动读取域的 `defaultNamingContext`；也可以手动填写，例如 `DC=example,DC=com`。
7. 点击“连接”。
8. 连接成功后会自动载入组织单位、用户和组；在“域用户”或“域组”页签中操作。

> 首次使用建议先用测试 OU、测试账号验证权限和密码策略，再用于生产账号。

## 需要的 AD 权限

不要求必须使用 Domain Admin。可以通过 AD 委派授予最小权限：

| 操作 | 需要的权限 |
| --- | --- |
| 查询用户/组/OU | 目标域或 OU 的读取权限 |
| 新建用户/组 | 目标 OU 的“创建用户对象”/“创建组对象” |
| 编辑用户属性 | 目标用户对象的相应属性写入权限 |
| 重置密码 | 目标用户的“重置密码”扩展权限 |
| 启用/禁用/解锁 | 目标用户的账户控制权限 |
| 修改组成员 | 目标组的“写入成员”权限 |
| 删除用户/组 | 目标对象的删除权限 |

生产环境建议专门创建一个管理账号，只委派必要的 OU 和操作，不要日常使用 Domain Admin。

## 安全设计

- **优先 LDAPS**：默认勾选 SSL，端口 636。
- **密码操作强制加密**：设置/重置密码前会检查连接是否已加密；未加密且未协商 SASL 加密时会直接拒绝，避免把密码或弱保护操作发出去。
- **明文连接警告**：取消 SSL 时会显示风险确认。
- **证书校验**：当前版本默认勾选“忽略证书错误”（按需求设置），勾选后会写入日志警告；生产环境建议取消勾选并部署受信任的 LDAPS 证书。
- **密码不写入日志**：审计日志只记录操作对象、DN 和必要参数，不记录密码。
- **删除确认**：删除用户/组必须输入登录名，且会检查内置对象、关键系统对象和当前连接账号。
- **密码保存默认开启**：“记住密码”默认勾选，使用 Windows DPAPI 当前用户范围加密；不保存时可在连接前取消勾选。换用户或换机器无法解密。
- **本地审计**：操作记录写入 `%APPDATA%\DomainUserManager\logs\`。

## 常见错误

| 现象/错误 | 可能原因与处理 |
| --- | --- |
| 用户名或密码错误（data 52e） | 账号格式不对、密码错误、账号被锁定或禁用。尝试 `域\用户名` 或 `用户名@域`。 |
| 权限不足（result 50） | 连接账号缺少目标 OU/对象的委派权限。 |
| 密码不满足策略（result 19 / data 52d） | 密码长度、复杂度或密码历史不符合域策略。换一个更复杂的密码。 |
| 同名对象已存在（result 68） | 显示名/登录名/组名与现有对象冲突。更换名称。 |
| 对象不存在（result 32） | 对象已被其他管理员删除，刷新列表。 |
| 域控制器拒绝操作（result 53） | 对象受保护、组类型转换不合法，或操作违反 AD 规则。 |
| 无法连接（81/91） | 地址、端口、防火墙或域控制器服务不可达。确认 636/389 端口开放。 |
| TLS/证书错误 | 域控制器证书不受信任或名称不匹配。当前版本默认忽略证书错误；生产环境建议取消勾选并部署受信任证书。 |
| 创建/重置密码失败并提示需要加密 | 当前是明文 LDAP 连接。断开后勾选 SSL，使用 636 端口重连。 |
| 修改组类型失败 | 组范围转换受 AD 成员规则限制（例如全局组包含其他域成员），AD 会拒绝。 |

## 数据与日志位置

```text
%APPDATA%\DomainUserManager\settings.xml
%APPDATA%\DomainUserManager\logs\audit-YYYYMMDD.log
```

程序不会把连接密码写入审计日志。点击日志面板中的“打开日志目录”可直接打开。

## 已知限制

- 单次查询最多显示 300 条用户/组记录，需要更精确的关键字缩小范围。
- 组成员/所属组最多读取 10000 条，超大组会被截断。
- 只管理用户和组，不包含 OU、计算机、联系人、Exchange 邮箱、LAPS、BitLocker 等对象的专用功能。
- 只针对一个基准 DN/域进行管理，不做多域林浏览。
- 组名和组登录名创建后不支持在此工具中直接重命名；组类型/范围的修改受 AD 规则限制。
- 不提供回收站恢复；删除是不可撤销操作。
- 修改 `sAMAccountName` 可能影响依赖旧登录名的脚本、映射和第三方系统，程序会二次确认。
- 不处理 MFA/条件访问；请使用有权限的服务账号或管理账号连接。
- 当前发布包未做代码签名，Windows SmartScreen 可能提示未知发布者；可自行签名后分发。
